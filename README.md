🥁 Virtual Acoustic Stage Drum Kit

An interactive, 3D-styled acoustic drum kit built using pure HTML, CSS, and JavaScript.Powered by the browser's native **Web Audio API** with zero external audio dependencies.

✨ Features
- 🥁 **Authentic Drum Kit Layout**: Bass Drum with kick pedal, Snare, Hi-Hats, Rack Toms, Floor Tom, and Cymbals.
- 🔊 **Web Audio Synthesis**: Real-time acoustic drum sound modeling without external MP3 files.
- ⚡ **Physics & Animations**: Cymbal wobbling, drumhead shockwave ripples, and kick pedal depression.
- 🎹 **Keyboard & Touch Controls**: Play using keyboard keys (<kbd>Space</kbd>, <kbd>S</kbd>, <kbd>H</kbd>, <kbd>T</kbd>, <kbd>G</kbd>, <kbd>F</kbd>, <kbd>C</kbd>, <kbd>R</kbd>) or mouse clicks.
- 🎶 **Play Drum Solo**: One-click automatic drum groove looper.
